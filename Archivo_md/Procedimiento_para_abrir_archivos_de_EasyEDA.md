# Procedimiento para abrir archivos de EasyEDA

Archivos a abrir:

- `Diseño_PCB_Camara`  
- `Diseño_PCB_Sensores` (pueden abrir la versión V1 o V2)  
- `Esquematico_camara`  
- `Esquematico_de_sensores_y_motores`

Tenerlos previamente descargados en la PC.

---

## Acceder a EasyEDA

Para este procedimiento no es necesario descargar el programa, se usará el editor WEB de EasyEDA.

1. Abrir el buscador de preferencia.  
2. Ingresar al link: [https://easyeda.com/](https://easyeda.com/)  
3. Una vez dentro de la página, para usar el editor WEB se necesita tener creada una cuenta de EasyEDA.  
4. En caso de no tener una cuenta, se crea seleccionando la opción **Register**:

<p align="center">
  <img src="Imagenes_pasos/registrol.jpg" alt="Opción Register en EasyEDA" width="800">
</p>

5. Una vez creada la cuenta (o si ya dispone de una), puede acceder mediante la opción de **Login**, ubicada en el área resaltada de la barra superior:

<p align="center">
  <img src="Imagenes_pasos/login.jpg" alt="Opción Login en EasyEDA" width="800">
</p>

---

## Abrir el Editor WEB

1. En la página principal, seleccionar la opción **Product** -> **EasyEDA Designer**:

<p align="center">
  <img src="Imagenes_pasos/diseño_online.jpg" alt="Opción EasyEDA Designer" width="800">
</p>

2. Seleccionar la opción **Standard Edition**:

<p align="center">
  <img src="Imagenes_pasos/editor.jpg" alt="Opción Standard Edition" width="800">
</p>

---

## Importar archivos

1. En la parte superior izquierda, seleccionar la opción **File** -> **Open** -> **EasyEDA...**

<p align="center">
  <img src="Imagenes_pasos/abrir_archivo.jpg" alt="Opción File Open EasyEDA" width="600">
</p>

2. Cargar el archivo con extensión `.json` de preferencia que previamente fue descargado.  
3. Repetir el proceso con cada uno de los archivos que se desean abrir.

---

## Importante

> **Nota:** Al abrir cada archivo en el editor WEB, este se abrirá en una pestaña distinta. Para cambiar entre un archivo y otro, basta con seleccionar la pestaña correspondiente.
